# Mango v13c final validation

The fixed final report has SHA-256 `f92a6d5619dd9aaf950841870d8f34fc4227922e77ee4e3311c64fb798fabf89`, status `partial`, 92 hosts, and reported internal wall time 377.67 seconds (benchmark orchestration reported about 379.82 seconds). Its host set is identical to v12j: no additions or removals. The 92 ownership decisions therefore reuse the v12j source/DEX review; only fact counts were refreshed.

Twenty-two hosts have semantic fact changes. This is chiefly candidate/object-identity churn rather than a clean capability increase. Large positive nets include ChannelSecondIndex +615, ChannelDynamicSecond +461, VideoSquare +207, WebContainer +125, RewardAdFree +80, ChannelBackyard +72, and OPOS AdWeb +23. Large negative nets include CloudLive -69, MGVideoPlay -50, and ErlangLive -36. Several zero-net hosts replaced 54 facts with 54 differently identified facts. The machine-readable delta records additions and removals separately.

The most direct XML improvement is WebContainerActivity: its source-proven `ShLayoutWebviewFragmentBinding.inflate(...)` path now yields three separately identified `ImgoWebView` union objects, raising 69 → 194 facts. The repeated 39-setting/15-operation surfaces are aliases or alternatives until branch/object identity is proven; the increase is not 125 new API methods. OPOS AdWebActivity retains its established `BaseWebActivity.b()` construction path and adds a second `|0` identity for the same `MoWebView` allocation chain; this is duplicate/candidate identity, not a new WebView class. RewardAdFree likewise changes XML/union identities around the already audited `ImgoAdWebView` family and contains heavy add/remove replacement.

Strict source-authored replay remains unchanged: 608/608 settings, 634/634 callbacks, 1,147/1,163 bridges, and 3/3 operations. The 16 bridge misses remain the 14 Loading/Rainbow handlers and two dynamic unscorable registrations. MG's 81 Diana facts remain covered. Full recall therefore does not validate the newly emitted aliases.

Binding confidence became more conservative: explicit facts fell from 21 to 5 while candidates rose from 42,249 to 43,624. Unknown WebView-type facts fell from 429 to 417. The exact host set and canonical recall are stable, but the large object-identity churn means v13c should not be described as a uniformly improved capability inventory.

The phase snapshot SkinDetail observation is retained with a correction. SkinDetail is absent from both final reports. Source proves a conditional title-bar share path passing `this` Activity to `MGShare.goShare`; consequently, the transient Tencent dialog facts are conditional candidates rather than proven wrong ownership. Their absence from the final result is correct for this comparison, and XML absence alone is not negative proof.
