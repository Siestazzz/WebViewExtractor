# Mango v16a source audit

v16a is a development result with mixed behavior. It restores the five source-verified conditional Diana hosts and all 81 constrained MGVideoPlay Diana facts. That recovery is consistent with the previously audited Fragment root, concrete OkHttp callback registration, posted Runnable, `bindService` ServiceConnection, and same-`DianaView` state join. It does not restore the four Erlang regression facts: their dedicated replay remains 0/4.

Removing construction-only callback reachability also removes source-real paths. The clearest groups are the Pangle `IESJSBridge` calls, whose SDK helper explicitly executes `addJavascriptInterface`; and the mgadplus `am.a.Q()` registrations, which explicitly call `BridgeWebView.t(name, handler)` for fifteen literal names and install the lifecycle callback. These disappear from RewardAdFree and MGVideoPlay. Both DTF FaceLoading hosts also disappear with their previously ownership-validated 24-row surfaces. Erlang loses five additional named Imgo handler semantics (`VideoInteractionEvent`, `VideoSetPlayerMuted`, `openSystemSetting`, `sendLocalPixelBarrage`, and `showInteractiveMagicCube`) while its earlier `mgTransfer` and `showMangPushShare` regression remains.

Many single operation losses are real callback bodies (`retry`, posted `run`, completion callbacks), but v16a does not yet model all actual interface calls or Lazy bodies. Their host reach is retained as unresolved for v16d rather than declared absent. The complete normalized set delta is saved separately; it excludes receiver and argument identities so alias multiplicity does not inflate this classification.
