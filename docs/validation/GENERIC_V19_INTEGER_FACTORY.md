# Actual metadata map and numeric factory selection

The frozen-v17 Browser trace identifies a second object boundary before retained Scene creation. The independent source/DEX evidence is xigua/browser-service-and-scene-reflection-source-v1.json. A selected-DEX summary read takes 1.79 seconds and establishes the following structure without a full APK analysis: an unbranched 1,128-instruction static initializer populates a literal-name -> boxed-integer map; a 681-instruction factory obtains the integer, unboxes it, and uses a packed switch to construct the selected service factory. The baseline factory summary joins many results into unknown.

Four generic limitations prevent actual selection: static field reads previously materialized the Map allocation without its initializer entries; Integer.valueOf/intValue lacked exact semantics; guard resolution intentionally avoided arbitrary method-return evaluation; and numeric factory refinement stopped at 500 instructions. The change addresses these specific boundaries without adding capability roots, enumerating unknown implementation classes, or interpreting arbitrary initializer helper bodies.

IntegerConstants recognizes only the complete Integer.valueOf(I)Integer and Integer.intValue()I descriptors. A boxed integer has a separate symbolic kind and exact payload; boxed zero is non-null. String "0", primitive/null zero, unknown receivers and incompatible signatures do not become an Integer payload. Unboxing null cannot select case zero.

StaticMapConstants folds a newly allocated actual static HashMap/LinkedHashMap only when a single target field assignment and the complete unbranched, nontruncated initializer entry set can be certified. Keys must be literal, values literal/Class/exact Integer boxing, entries unique and at most 256, initializer at most 4,096 instructions. The same raw allocation can receive exact standard Map.put through its interface. Only its standard default constructor and certified put operations are accepted; aliases, helper escapes, mutations, branches, duplicate assignments, unknown values and unsupported constructor calls prevent certification. Entry construction and deadline checks complete before atomic publication. No partial folded map is marked complete.

The certificate belongs to the actual Map identity and the Host. Ordinary put or other modeled Map mutation invalidates it, as does publishing the actual Map as a field alias or passing it to an unapproved callee. An unresolved Map-capable argument or erased returned alias conservatively revokes remaining certificates. Iterator/entry exposure is not a read whitelist. Guards may read only a currently certified same-object Map with an actual resolved key; no arbitrary getter body is executed as a guard. Unknown keys retain uncertainty. An absent exact key is null, not boxed integer zero. This is a local modeled-write/escape boundary, not a whole-program proof that arbitrary unanalyzed callees cannot access public static state without arguments.

DexFlow additionally admits static object-producing factories with a single packed/sparse switch and forward control flow, up to the existing 4,096-instruction special-factory size boundary. It specializes only a context that resolves a previously unknown numeric guard. Backward edges retain the conservative summary; oversized candidates emit summary_switch_factory_budget. The shared 16-variant limit, existing variant reuse, global decode/work/deadline limits and conservative fallback are unchanged.

IntegerSwitchFactoryFixture covers a 200-arm factory through real literal metadata, boxed numeric selection and actual interface dispatch producing capabilities on three distinct WebViews. It checks absent/wrong keys before variant exhaustion, unknown selectors without new variants, boxed zero vs null/string, ordinary put/clear/remove/putAll, actual aliases and unknown escape, conditional/mutated initializer rejection, the 16-variant fallback/reuse and 4,096-size boundary. StaticMapCertificateFixture adds standard Map interface put, a large sparse switch, initializer escape/alias/overwrite, backward edges and erased returned alias invalidation. Both are invoked by CapabilitySelfTest. capabilitySelfTest, compactReportTest and shadowJar pass in 34 seconds, test/runs/generic-v19-integer-factory-full.log.

The actual packaged-method replay and frozen artifact hashes are in xigua/v19-selected-service-factory-replay.json. Frozen v18 returns unknown; frozen v19 returns the exact independently proved BrowserServiceFactory allocation at offset 572 in 2.50 seconds, with one refined summary and a 223-entry certified map. An absent real metadata key returns null in 2.65 seconds and does not select case zero. The replay reads only three selected packaged classes and invokes the exact factory with a literal name. It does not execute Application startup, plugin routing, getService's cache/wrapper chain, Activity roots, or new WebView attribution. Full Browser recovery is not claimed.

Production changes are CapabilityEngine.java, DexFlow.java, IntegerConstants.java and StaticMapConstants.java; tests are CapabilitySelfTest.java, IntegerSwitchFactoryFixture.java and StaticMapCertificateFixture.java.
