The earliest analyzer gap is narrower than the old “inheritance” description. Direct Activity allocation reaches `e`/`p` and their superclass. The first nontrivial relation is in inherited `h0` construction: preserve `o.ʻ(context)`'s returned `b1` through its field write, then preserve `b1.ʾ()`'s returned `n2` through `h0.ˊˊ` and the inherited `h0.ˆˑ()` field-return accessor. A reusable implementation should model this return → field → field-return chain on the same allocated receiver, then follow the explicit `n2` ↔ manager backlink. Type-only propagation would be unsafe because both the controller pool and YSP service can supply multiple instances.
