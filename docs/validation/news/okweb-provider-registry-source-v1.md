The first snapshot is a conditional implementation inventory, not yet an accepted positive oracle. The manager map, configuration-to-pool factory and container transfer are explicit, but the actual Application/service entry reaching configuration and exclusion of competing first initialization remain open. positive_acceptance=false until these edges are proved.

The custom bridge uses module/method selectors from URL authority/path and a query Map. Its reflective rule is public inherited getMethod(method, Map.class) plus NewJavascriptInterface; external modules use a dedicated forwarding path. Lazy subclass conflict handling can remove a base module and suppress adding the subclass because the add flag remains true. Transparent endpoint exposure therefore needs literal registry-state reasoning; an inheritance union would be unsound. Full source hashes and bodies are preserved in the companion JSON.
