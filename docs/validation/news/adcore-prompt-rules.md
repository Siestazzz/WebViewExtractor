# Reusable AdCore prompt and Midas wrapper rules

`AdCoreJsWebChromeClient.onJsPrompt` uses prompt message parameter 2 as JSON input and calls the `AdCoreJsBridge` stored from constructor parameter 0. `AdCoreJsBridge` is its own reflection receiver: this APK has a `jsMap<String,Method>` and no separate instance map. Its constructor calls `initDelegate`, which calls `initJsMap(isSafe, AdBasicInterface.class)`. The registry enumerates public methods, tests `Method.isAnnotationPresent`, builds a key from the Java method name and parameter suffixes, then stores the `Method`. There is no `getAnnotations` call in this implementation.

`@AdBasicInterface` is a marker with no name member, so the JS method name is the DEX/Java method name. The generated key appends `_S`, `_N`, `_B`, `_O`, `_F`, `_[LS`, `_[LN`, or `_P` according to each parameter. Prompt JSON contains `method`, `types`, and `args`; dispatch rebuilds the same key, looks it up, optionally retries `_O` as `_S`, and invokes the method on the same bridge instance. `MraidBridge` is the injected JavaScript namespace rather than an `addJavascriptInterface` registration name.

`AdCoreWebViewHelper.setJsWebChromeClient` is the object-identity join. Parameter 0 is the wrapper, parameter 1 is the bridge, and parameter 2 is an optional prebuilt client. The helper stores parameter 0 through `bridge.setWebView`, then registers either parameter 2 or a client constructed from parameter 1 on that same wrapper. A type-only join across other `AdWebViewWrapper` implementations is invalid.

For Midas, both wrappers receive the concrete WebView at constructor parameter 1 and store it in `mWebview`; parameter 0 is only the Activity context. Their constructors synchronously call `InitWebView`, so its settings and client calls belong to the exact WebView passed at parameter 1. `APSystemWebPage.initUI` and `APX5WebPage.initUI` create the respective wrapper and store it in their `webView` field. This constructor-to-field relation is the missing receiver binding needed to recover Midas settings without propagating through Context.
