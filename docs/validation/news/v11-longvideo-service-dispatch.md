The first analyzer relation to add is therefore the registry flow, rather than another factory-return rule: `(same y2 instance, exact Class constant)` from `put` to later `get`. The result must remain tied through the `player.g` constructor field and interface call. Matching only the `qnplayer.n` type would cross-bind unrelated players; matching only `n.class` without the same registry receiver would do the same across pages.
