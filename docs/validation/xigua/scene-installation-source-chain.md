BrowserActivity selects service-created Scene, passes the same captured instance back through SceneComponentFactory and installs NavigationScene with a LifeCycleFragment transaction. Fragment onActivityCreated forwards into SceneLifecycleDispatcher and SceneLifecycleManager. NavigationScene invokes the registered root factory and pushes its result; BrowserScene onCreateView initializes e=p1(view), and onActivityCreated applies SSWebSettings to e. This is a concrete framework installation route, not mere allocation or a scene class-name mention. Java decompilation shows a questionable additional fallback push; its branch dominance has not been inferred.

Reusable mechanism: Activity -> generic lifecycle container -> registered root factory callback -> returned custom Scene -> Scene lifecycle WebView. A tool limited to Android Fragment names or direct calls can miss this route; this is a source-derived test target, not an observed report defect.
