# Generic v15: filter unrelated map writers before decoding

The existing transport registration certificate requires the actual Map.put receiver expression to be a field in the previously discovered transport-field set. The DEX index already records all direct field references per method. Therefore a method whose indexed field references are disjoint from that set cannot produce the existing certificate. The second discovery pass now checks this necessary condition before decoding method bodies. The first discovery pass, callback certificate, exact put contract, local deadline and per-query writer prefilter remain intact.

ReflectionDiscoveryPrefilterFixture contains a real annotated reflective dispatch and its actual registry-field writer, plus65 unrelated map-writing methods (map parameters and an unrelated field). Frozen v14 accepts the real writer but decodes the irrelevant bodies, failing the new regression. The isolated ReflectionProtocols override keeps the positive writer and skips all65 unrelated bodies. Hashes and both outputs are recorded in experiments/v15-reflection-field-prefilter.json.

This preserves the existing structural certificate; it does not extend support to arbitrary map getters or parameter-only transport registries. Real-App speed and recall require separate measurement.
