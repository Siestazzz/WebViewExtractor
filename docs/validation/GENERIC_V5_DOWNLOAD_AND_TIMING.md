# v5 DownloadListener and export timing

The source audit identified a systematic missing callback category: actual WebView.setDownloadListener registrations and inherited onDownloadStart implementations. These are part of the requested WebView callback surface; their source facts remain in the cumulative oracle rather than being excluded to improve recall.

Production recognition requires the WebView SDK family and full setter descriptor, including void return. Android and Tencent X5 use their respective DownloadListener interfaces. Callback members require public instance implementations of onDownloadStart(String,String,String,String,long):void; inherited implementations retain their defining signature while the registration retains the actual object type. Existing per-WebView binding, null callback removal and virtual API override handling apply unchanged. Client getter dependency propagation also includes these listener interfaces.

The Android descriptor was checked against the local official API36 android.jar with javap. Tencent declarations and a real installation chain were independently source-verified by GPT-6.1 Sol in the Txws patched APK, recorded in sohuvideo/download-listener-sdk-source.json. Sohu did not contain the Tencent interface definition, so no definition was inferred from an instrumentation reference alone. No private App type is used by the implementation.

DownloadListenerFixture exercises both SDK families, inherited callback signatures, real child identity, two-WebView separation, null reset, wrong SDK family, static callback and unrelated owner/overload negatives. The Android fixture fails on frozen v4 because the Activity capability is absent, and both families pass on v5. A real-App recall improvement is not claimed until frozen ten-App replay finishes.

Main.write previously counted nested compact/counts exports both inside their parent write duration and again as child durations. v5 subtracts already-recorded nested time from the outer accumulation, preserving the individual-file count. CompactReportTest verifies reported export time is positive and does not exceed externally measured wall time, and that a detailed export writes three files. Frozen v4 fails this test; the corrected writer passes. This corrects a subphase metric, not analysis performance. Historical external total wall-clock measurements remain valid and are not rewritten.
